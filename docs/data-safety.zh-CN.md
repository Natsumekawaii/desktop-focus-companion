# 自动持久化与数据安全

## 可选 AI 与离开设备的数据

开发分支中的 DeepSeek 助手默认关闭，启动时不会请求模型列表或对话接口。用户主动测试 Key 时仅请求官方模型列表；同意启用后发送消息才会调用官方 HTTPS 对话接口。对话及相关专注记录、名称和按需读取的备注会发送给 DeepSeek，不上传整个数据库文件。调用可能产生费用，并适用提供商的数据处理规则；不支持第三方中转地址。

各数据配置的 `agent/conversations.sqlite3` 保存聊天和非敏感偏好。删除聊天不会删除专注记录，也不会向提供商请求删除其已处理的数据。聊天文件是普通本地 SQLite，不是加密存储。没有跨会话记忆；请求上下文按完整轮次裁剪，较早内容仍保留在本地。

Key 使用 Windows 凭据管理器，凭据标识由当前数据目录生成，开发版与安装版的 Key 和对话相互隔离。安全存储失败时只在本次运行中保留 Key，重启后 AI 再次停用。不要把 Key 发到聊天或 Issue；删除数据配置前可在 AI 配置中删除凭据。普通卸载保留用户数据和凭据，不会自动撤销 DeepSeek Key。

工具仅允许指定的记录查询和变更，不提供 SQL、Shell、任意文件、设置、项目管理或计时器控制。模型文本和数据库备注不能授予权限。完整的单条新增可以自动保存；修改、删除、重叠新增及所有批次都需要确认预览。字段不明确时继续追问。每个计划最多 50 条，每轮最多一个计划、8 次模型请求。

客户端只在内存保留未完成的写入范围。相关补充信息可完成请求，但取消、新话题、切换会话、关闭窗口或重启会清除权限，保存的聊天文字不能恢复授权。字段证据必须引用真实用户消息片段。计划生成前最多一次格式纠正，可调整证据语法或删除多余的删除参数，不能改变字段值、目标或数量，不能绕过缺失信息、时长冲突或确认，更不会重放已提交的写入。确认卡展示完整批次与可读差异；过期预览禁用确认。

`apply_changes` 在 SQLite 事务内验证完整记录／项目快照、时区和重叠记录，保留未改动的有效时长与计时元数据，并在现有 settings 表保存最小防重复回执。主数据库仍为 v5。提交前取消会整批回滚；停止或断网不会撤销已提交事务。重启通过回执修正中断的聊天状态，不重新执行操作。工具预览包含记录数据，截图应使用模拟配置。

Markdown 不执行 HTML、不加载图片或文件。网络请求头、Key、对话响应及推理内容不写入日志。DeepSeek 工具续接需要保留推理内容，因此它随会话保存在本地，界面只展示思考状态。敏感内容遮蔽仅是额外防护，不意味着可以在项目备注或聊天中放入秘密。

Desktop Focus Companion 1.0 采用本地优先设计，不设置“保存／应用”工作流。

## 即时持久化

- 计时器完成：立即执行 `FocusSessionRepository` 事务。
- 确认手动记录：立即执行事务，并设置 `source=manual`。
- 创建带颜色的专注项目及重命名：立即执行事务。
- 确认删除专注项目：在同一事务中永久删除关联记录和项目；失败时同时回滚。
- 目标／连续专注偏好：立即更新 SQLite 设置。
- 常规、桌面伙伴、专注和外观设置：立即写入或经过 250 毫秒防抖后原子写入 JSON。

## 原子设置写入

设置先序列化到同目录临时文件，依次执行 flush 和 fsync，再通过 `os.replace` 原子替换正式文件。损坏的 JSON 会保留为带时间戳的诊断副本，然后加载默认设置。

## SQLite 可靠性

- 每个连接均启用外键；
- 设置 5 秒忙碌超时；
- Repository 操作全部参数化；
- 数据库迁移使用显式事务并支持失败回滚；
- 迁移后执行 `quick_check` 和 `foreign_key_check`；
- 恢复令牌保持唯一，保证待保存记录幂等。

应用绝不会通过删除数据库来修复故障。

明确批准的生命周期升级是唯一例外：首次运行事务会永久删除旧版 `is_archived=1` 项目及其关联记录，清除剩余的收藏标记，并写入初始化标记。整个事务要么全部完成，要么全部回滚。当前活动、待保存或可恢复的专注项目无法删除。

分钟精度升级同样是一次性显式操作：独立的 schema v5 事务会删除不足 60 秒的旧专注记录，将其余非整分钟时长向下取整为完整分钟，并写入初始化标记。任何语句失败时，记录和标记都会一起回滚。

## 活动会话检查点

`active-session.json` v4 保存专注项目身份与名称快照、开始时间、已确认的实际累计时长、计时器状态、模式、可选目标、备注、恢复令牌、最近检查点以及可选的待确认结束时间。状态变化时以及每隔 30 秒都会原子写入。

加载器兼容 v1／v2／v3 旧字段。恢复后状态固定为暂停，不会把应用停机时间计入专注。无效的检查点会保留用于诊断并被安全忽略，不修改 SQLite。

## 用户资源与构建隔离

用户数据库、设置、自定义桌面伙伴图片、自定义应用图标、旧版导出文件及日志均位于 `%LOCALAPPDATA%\DesktopFocusCompanion`。PyInstaller 的 `build/` 和 `dist/` 不包含用户数据，清理这些目录不会删除 AppData 中的数据。

自定义资源缺失或损坏时，应用会回退到内置默认资源并继续可用。重置操作只清除被选择的自定义资源设置，不影响其他偏好。

## 明确不提供的备份功能

Desktop Focus Companion 当前不提供定时备份、ZIP 备份、清单、保留策略、恢复管理器、备份历史或 CSV 导出。

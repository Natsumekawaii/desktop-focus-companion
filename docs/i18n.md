# Desktop Focus Companion 国际化开发指南

Desktop Focus Companion 当前支持以下界面语言：

- 简体中文（`zh-CN`）
- English（`en-US`，旧版本设置缺少语言字段时的兼容默认值）

## 实现方案

国际化入口位于 `app/i18n/translator.py`。`LocalizationManager` 负责加载语言目录、维护当前语言、设置 Qt 默认 `QLocale`，并通过 `language_changed` 信号通知所有已打开窗口即时重译。组件使用 `tr("semantic.key")` 获取文本，不根据语言代码自行编写条件分支。

日期、月份与星期通过同一模块中的 `format_date`、`format_datetime`、`format_month_year`、`format_time` 和 `format_weekday` 格式化。紧凑时长通过 `app/timer/formatting.py` 统一格式化并引用翻译资源。

语言选择保存在用户数据目录的 `settings.json` 中：

```json
{
  "language": "zh-CN"
}
```

切换语言时会先原子写入设置，再广播运行时变更。应用重新启动时会在创建任何窗口以及显示启动错误对话框之前加载该字段。旧设置文件无需迁移，缺少或包含无效语言代码时安全回退到 `en-US`。

## 翻译资源

集中式 JSON 语言目录位于：

```text
app/i18n/locales/
├── en-US.json
└── zh-CN.json
```

两个目录必须包含完全相同的语义键。启动时会验证键集合；缺失或多余的键会被视为开发错误。PyInstaller 配置会将整个目录复制到发行包。

## 新增界面文本

1. 在所有现有语言 JSON 中添加同一个语义键，例如 `dashboard.empty.no_sessions`。
2. 在界面或控制器中调用 `tr("dashboard.empty.no_sessions")`。
3. 含变量的文本使用命名占位符，例如 `{count}`；所有语言必须使用兼容的占位符。
4. 可复数化内容使用明确的 `.one` / `.other` 键，由业务代码按数量选择语义键。
5. 窗口内的静态文本应在 `retranslate_ui()` 中设置，并连接 `language_changed`。
6. 已格式化的日期、时长或统计值需要保存原始数据，并在语言变化时重新格式化。
7. 用户输入的 Focus Item 名称、Note、文件名等数据不得翻译。

## 新增语言

以增加日语为例：

1. 复制 `en-US.json` 为 `ja-JP.json` 并翻译全部值。
2. 在 `SUPPORTED_LANGUAGES` 中加入 `Language("ja-JP", "日本語")`。
3. 保持所有目录键集合一致，并运行完整测试。
4. 在最小与常用窗口尺寸下检查 Settings、Focus Panel、Dashboard、表格、对话框、菜单和 Tooltip。

无需修改 Settings 下拉框、持久化层或打包脚本；它们会从支持语言清单和资源目录自动工作。

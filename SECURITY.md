# Security Policy / 安全策略

## 简体中文

### 支持范围

| 版本 | 安全更新 |
| --- | --- |
| 1.0.x | 支持 |
| 更早版本 | 不支持 |

### 报告安全问题

请使用 GitHub 的[私密漏洞报告](https://github.com/Natsumekawaii/desktop-focus-companion/security/advisories/new)，不要在公开 Issue 中披露利用步骤、用户数据或尚未修复的漏洞。

报告中请包含受影响版本、Windows 版本、复现步骤、潜在影响和建议修复（如有）。维护者会尽快确认报告、评估影响，并在修复可用后协调披露。请勿访问不属于你的数据，也不要通过破坏性测试验证问题。

## English

### Supported versions

| Version | Security updates |
| --- | --- |
| 1.0.x | Supported |
| Earlier versions | Unsupported |

### Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Natsumekawaii/desktop-focus-companion/security/advisories/new). Do not disclose exploit steps, user data, or an unpatched vulnerability in a public issue.

Include the affected version, Windows version, reproduction steps, potential impact, and a suggested fix when available. The maintainer will acknowledge the report, assess its impact, and coordinate disclosure after a fix is available. Do not access data that is not yours or use destructive testing to validate a report.
